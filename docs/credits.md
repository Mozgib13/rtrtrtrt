# Кредиты и лицензии

## Это фанатский некоммерческий проект

- **DayZ**, **Chernarus**, **Livonia**, **Sakhal** — товарные знаки и игровые данные
  Bohemia Interactive a.s. Карта **Krasnoyarsk** — фанатская работа,
  не аффилирована с Bohemia Interactive и не поддерживается ею.
- Ванильные игровые поверхности (`DZ\...`) используются через игру и не
  распространяются в этом репозитории (нет бинарей DayZ в git — только наши файлы).
- Использование карт с чужими ассетами: запрещено; используйте либо ванильные
  ассеты DayZ, либо свои/CC0/CC-BY с указанием авторства.

## Источники при создании

- **Project-Everglades / DayZ-Resources** (GitHub, CC-BY-SA) — структура проекта TB,
  примеры `layers.cfg` (пути `DZ\surfaces...` взяты оттуда), шаблоны `config.cpp`,
  форматы CE XML. Кредитуем и благодарим авторов.
- **zen0bit / DayZmap-Template** (GitHub) — классический пайплайн TB (heightmap asc,
  xllcorner=200000, rebuild terrain, 4 materials per cell).
- **RaG PBO Builder** (Tyson89, GitHub) — бесплатный сборщик PBO с подписью.
- **Bohemia Interactive** — DayZ Tools, Terrain Builder, World Editor.
- Рельеф сгенерирован процедурно (Python + numpy), стилизован «под Красноярск»
  без использования геоданных NASA/OSM (см. `docs/11-advanced-geo.md` для полного
  гео-варианта).

## Лицензия на наши файлы

Код генератора (`tools/`), документация и сгенерированные исходники — можно
свободно использовать для своего сервера и модов, включая коммерческий хостинг
своего сервера, с указанием авторства «Krasnoyarsk Map Project».
Распространение модифицированной версии мода — на ваш страх и риск; если будете
публиковать публично — согласуйте видимость Workshop (Friends Only / Unlisted).
