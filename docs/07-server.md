# 07. Сервер: запуск, приватность, распространение

Отвечаем на главный вопрос сразу:

> **Карту нельзя сделать «только серверной».** DayZ устроен так: клиент и сервер
> должны загрузить одни и те же моды в одном и том же порядке. Мир отрисовывает
> клиент у себя — значит, у каждого игрока должна лежать папка `@KrasnoyarskMap`.
> `-serverMod=` подходит только для серверных скриптов (админ-меню, логи, CE-правки),
> но не для террейна. Так работают все кастомные карты: Намальск, Deer Isle, Ливония,
> Сахалин.

Что МОЖНО сделать, чтобы картой пользовались только на вашем сервере:

1. **Не публиковать мод в Steam Workshop как «Public».** Два рабочих варианта:
   - вообще не публиковать — выдавать `@KrasnoyarskMap` своим игрокам вручную
     (Discord, личная ссылка). Игра кикает без мода — посторонние просто не зайдут;
   - **Workshop с видимостью «Friends Only» / «Unlisted»** — мод в мастерской,
     но скачать его могут только ваши друзья/по прямой ссылке; обновления прилетают
     автоматически. (Проверьте в DayZ Tools → Publisher, что видимость выставлена
     не Public. «Unlisted» есть не у всех типов контента — если его нет, используйте
     Friends Only или полностью ручную раздачу.)
2. Выдавать `@KrasnoyarskMap` только своим игрокам (Discord, личное сообщение,
   приватная ссылка).
3. Сервер — с паролем (`password = "...";`) и приватным AFK/рейт-проверками.
4. `verifySignatures = 2` + ваш `Krasnoyarsk.bikey` в `keys\` — подменить PBO
   на клиенте и зайти невозможно: сервер принимает только файлы, подписанные
   ВАШИМ ключом. Чужой сервер поднять с вашей картой тоже не получится,
   пока он не украдёт файлы вместе с ключом.
5. Юридически/технически **запретить передачу файлов между игроками нельзя**:
   игра требует полную копию у клиента, утечка через «своих» — это риск любого
   приватного мода. Помочь может только договорённость в правилах + небольшой
   комьюнити. PBO можно обфусцировать лишь частично — не стоит.

Итого: стандартная практика приватных карт = «не паблишить + пароль + .bikey».
Этого достаточно для игрового сообщества из десятков–сотен человек.

## 7.1 Установка сервера (Windows, self-hosted)

```cmd
REM SteamCMD
steamcmd +login anonymous +force_install_dir C:\dayzserver +app_update 223350 validate +quit
```

Структура после установки: `C:\dayzserver\DayZServer_x64.exe`, `serverDZ.cfg`,
`mpmissions\dayzOffline.chernarusplus\`, `keys\` (ванильные .bikey).

## 7.2 Установка мода на сервер

1. Скопируйте собранную папку `@KrasnoyarskMap\` рядом с `DayZServer_x64.exe`
   (`C:\dayzserver\@KrasnoyarskMap\`).
2. Скопируйте `Krasnoyarsk.bikey` из своей сборки в `C:\dayzserver\keys\`.
   (`.biprivatekey` на сервер НЕ копируйте никогда.)
3. Подготовьте миссию `dayzOffline.krasnoyarsk`:
   - скопируйте `mpmissions\dayzOffline.chernarusplus` → `mpmissions\dayzOffline.krasnoyarsk`;
   - замените в новой папке `cfgeventspawns.xml` и `cfgplayerspawnpoints.xml`
     файлами из `mission\dayzOffline.krasnoyarsk\` этого репозитория.
4. В `serverDZ.cfg` измените ТОЛЬКО строку миссии:
   ```cpp
   class Missions { class DayZ { template = "dayzOffline.krasnoyarsk"; }; };
   ```
   и при необходимости имя/пароль. Конфиг можно взять за образец из
   `server\serverDZ.cfg.sample` (там же прописан `verifySignatures = 2`).
5. Запуск (см. `server\start-krasnoyarsk.cmd.sample`):
   ```cmd
   DayZServer_x64.exe -config=serverDZ.cfg -port=2302 -profiles=profiles ^
     -dologs -adminLog -netLog -freezecheck -mod=@KrasnoyarskMap
   ```
   Обратите внимание: **`-mod=`, не `-serverMod=`**.
6. Порты: UDP 2302 (+ 2303, 2304) открыты в файрволе. В логах (`profiles\`)
   при старте должно быть `Krasnoyarsk` в списке загруженных модов и отсутствие
   `signature ... not valid`.

### Linux

То же самое, серверный билд для Linux существует (`DayZServer` через SteamCMD).
Обратите внимание на регистр имён файлов — PBO чувствительны к пути внутри
(Windows-стиль `Krasnoyarsk\world\...` в worldName — норма и на Linux-сервере,
так устроены все PBO DayZ).

## 7.3 Клиентская часть (каждый игрок)

1. Дайте игроку папку `@KrasnoyarskMap\` — её нужно положить в
   `<Steam>\steamapps\common\DayZ\`.
2. Запуск:
   - вариант A: ярлык DayZ с параметром `-mod=@KrasnoyarskMap`;
   - вариант B (удобнее): **DayZ Launcher** → закладка «Моды» → добавить мод →
     играть.
3. Игрок НЕ должен ничего подписывать — .bikey игра проверяет сама.
4. Оба клиента (сервер и игрок) должны иметь **одинаковую сборку мода**
   (иначе «Mod version mismatch»/кик при заходе). Раздайте всем один и тот же архив,
   версию пишите в Discord («карта Krasnoyarsk v1.0»).

## 7.4 Хостинги (GPortal, Nitrado, gameshosting…)

На большинстве хостингов кастомные карты требуют либо (а) включённого приёма
пользовательских модов, либо (б) публикации в Workshop (тогда мод станет публичным —
вам это НЕ нужно). Напишите в поддержку хостинга образец:

> Здравствуйте. Хочу установить приватную кастомную карту DayZ (не из Workshop):
> приложение -mod=@KrasnoyarskMap, отдельный .bikey в keys сервера, миссия
> dayzOffline.krasnoyarsk в mpmissions. Возможна ли загрузка пользовательских
> PBO и .bikey на выделенный сервер? Если нужен Workshop — возможна ли публикация
> «unlisted»/«private» либо выгрузка в каталог модов хостинга без публичной страницы?

Если хостинг требует Workshop — используйте вариант «Workshop с ограниченной
видимостью» из списка выше (Friends Only / Unlisted) либо поднимайте сервер сами
(есть готовые Windows/Linux-гайды; на 12 км карте хватит 4-6 vCPU + 8–16 GB RAM
на 60 слотов).

## 7.5 Чек-лист «сервер поднялся»

- [ ] В логах старта есть `[2026-..:..] :: Mod: KrasnoyarskMap` без ошибок подписи.
- [ ] В serverlist сервер виден с бейджем модов (или по прямой ссылке Steam://host/...).
- [ ] Клиент с `-mod=@KrasnoyarskMap` заходит, мир грузится, река/остров/город на месте.
- [ ] Лут спавнится (проверьте утром по зонному репорту `profiles\` → ECONOMY LOG).
- [ ] Зомби... либо есть (если вы расставили дома и сделали mapgrouppos.xml, см. mission README), либо отсутствуют — это ожидаемо для пустой карты.
- [ ] Клиент БЕЗ мода кикается при коннекте с нужным сообщением об отсутствии мода — так и должно быть.

## 7.6 Чего не надо делать

- Не ставьте `verifySignatures=0` на боевом сервере — это отключает проверку МОДОВ клиента.
- Не распространяйте `Krasnoyarsk.biprivatekey` никому и никогда.
- Не пытайтесь положить карту в `-serverMod=` — сервер просто не стартует (или игроки зайдут в пустой мир).
- Не редактируйте PBO клиента сервера вручную — собирайте заново из P: диска.
- Не копируйте на сервер ванильные Chernarus-PBO с перекрашенными текстурами — вас ждёт вечный разъезд версий.
