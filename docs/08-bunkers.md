# 08. Бункеры и подземка: как это делается в DayZ

Короткий честный ответ: **в DayZ нельзя «выкопать» комнату в земле.**
Террейн — это высотное поле (одно значение высоты на 6×6 м): у него нет
болеановских операций, нет «дыры с комнатой» как в Source/UE.
Поэтому все «подземные» объекты в Намальске/Deer Isle/Livonia сделаны одним
из трёх способов ниже. Мы заложили все три в проект.

## Способ 1. Яма + крыша-префаб (уже заложен в рельефе)

Что сделано генератором: три плоскодонные квадратные ямы глубиной 3.5–4 м:

| ID | Координаты (X, Z) | Яма | Дно |
|---|---|---|---|
| B1 «Столбы» | 8400, 1600 | 26×26 м | ≈ +29 м (предгорья) |
| B2 «Заводской» | 8080, 2560 | 24×24 м | ≈ +5 м |
| B3 «Емельяново» | 3310, 8660 | 24×24 м | ≈ +26 м |

(Точные высоты дна — в `docs/09-coordinates.md`; генератор печатает их сам.)

Как используется:

1. В **Object Builder** (DayZ Tools) собираете префаб бункера:
   — размер под яму (24×24 м), вход-пандус с одной стороны;
   — пол префаба на высоте дна ямы (Y объекта = высота дна);
   — «крыша» префаба слегка выше окружения (или вровень — тогда бункер
     читается как вкопанный).
2. Ставите префаб в TB/World Editor в координаты ямы.
3. Внутри — зоны спавна лута: наши `StaticMedDrop` уже прописаны по этим точкам.

Плюсы: просто, надёжно, не ломает маршрутки зомби.
Минусы: интерьер ограничен 3.5–4 м высоты (но для военного бункера — то что надо).

## Способ 2. Вход в склоне горы (как «Столбы» / bunkers в Livonia)

Самый красивый вариант, работает и без ям:

1. Выбираете склон (у нас их много по юго-восточному кряжу; координаты
   останцев — в `docs/09-coordinates.md`).
2. В префабе делаете туннель-вход в горе: пологие ступени/пандус в декорациях
   устья + длинный коридор (геометрия ниже поверхности рельефа).
3. Внутренние комнаты — часть того же P3D, они просто ниже z=0 плоскости склона.
4. Требования к префабу: геометрия интерьера **не должна торчать** из склона;
   внешние декорации устья расположите так, чтобы скрыть шов; свет внутри
   комнат — ваши лампочки (светильники как часть префаба или точечные огни).
5. В TB яму НЕ выкапываем: рельеф естественный, бункер «внутри горы».

Плюсы: выглядит как настоящий бункер, много места внутри (5–8 м высоты).
Минусы: нужно правильно подрезать уклон и тестировать на покерезание
(терраин может «пролезать» сквозь стены — лечится более глубоким залеганием
префаба, 1–2 м запаса — самый надёжный приём).

## Способ 3. «Фальш-бункер» (дёшево и сердито)

Здание-декорация с дверью внутрь (нема интерьера, только козырёк и дверь),
стяжки вокруг — чисто атмосфера. В отдельных случаях (жанр, RP-сервер)
достаточно. Не требует ничего, кроме одного префаба — но настоящим бункером
не является.

## Что из этого выбрать (рекомендация)

Для военного бункера под Столбами — **способ 2** (вход в горе, «пещера» с комнатами),
B1–B3 оставьте для склада/хранилища (**способ 1**).
Для подвала обычного дома (ваш случай «углубления в земле для подвалов») —
**способ 1 в миниатюре**: 1.2–1.5 м углубление + высокий цоколь у здания;
второй вариант — бункер-префаб способом 2 под зданием (здание сверху, вход с улицы).

## Как собрать префаб (кратко)

1. **Object Builder** → открыть исходную модель (например, `Land_Bunker_Small_DE`,
   если найдёте в `P:\DZ\...` — ищите по слову `bunker` в дереве P:;
   подходят также советские военные постройки; либо импортируйте свою FBX/OBJ).
2. Настроить маску геометрии, named selection `env_land` / `env_leveled`
   (для наземной части), memory LOD, UV под RVMAT (можно использовать ванильные
   бетонные/металлические RVMAT — не выдумывайте новые пути без нужды).
3. Экспорт в `P:\Krasnoyarsk\structures\bunkers\` как `Land_Krasnoyarsk_Bunker_01.p3d`.
4. В TB: Object Library → Other objects (или по прямому пути) → расставить → rebake.

## Частые ошибки

- **Пол бункера выше дна ямы** → щель между землёй и полом; спавнитесь строго
  на дно или чуть ниже кромки.
- **Интерьер торчит из склона** → перенести префаб глубже (на 1–2 м).
- **Зомби забредают внутрь** → для бункера без navmesh это исключено
  (они там не ходят вообще); если navmesh есть — интерьер всё равно недостижим
  без связей входа; оставьте как фичу (RP-бункер — убежище от толпы).
- **Лут в бункере не спавнится** → добавьте точку в `cfgeventspawns.xml`
  (у нас уже есть `StaticMedDrop` в B1–B3) и координаты здания в `mapgrouppos.xml`
  после того, как поставите префаб.
