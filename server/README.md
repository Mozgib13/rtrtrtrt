# Серверные файлы

- `serverDZ.cfg.sample` — образец конфига (в первую очередь: `template = "dayzOffline.krasnoyarsk"`,
  `verifySignatures = 2`). Детальное пояснение: `docs/07-server.md`.
- `start-krasnoyarsk.cmd.sample` — командная строка запуска сервера с `-mod=@KrasnoyarskMap`.

Файлы намеренно с расширением `.sample` — они не перезапишут ваш рабочий конфиг.
Скопируйте их под нужными именами и отредактируйте.
